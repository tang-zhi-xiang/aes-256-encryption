# aes-256-encryption
Uses AES-256 encryption and X25519 key exchange to send encrypted messages from sender.py to recv.py.

This only works on LAN

To run this program, open the terminal and split it. Then, use the command: 'python recv.py' on 1 terminal first and the command: 'python sender.py' on the other. After that, the program can be used by entering messages on the terminal running sender.py.
